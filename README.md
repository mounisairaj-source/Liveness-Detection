# Face-AntiSpoofing-Detection
The Face AntiSpoofing Detection will detect the person infront of cam is real or fake using SSL mobile netv3 model 
Face Anti-Spoofing using Vision Transformer (ViT) with DINO Self-Supervised Learning
A deep learning-based liveness detection system that distinguishes real faces from spoofing attacks (printed photos, video replays, 3D masks). The model leverages a Vision Transformer (ViT) backbone pre-trained with DINO self-supervised learning and fine-tuned for binary classification on face anti-spoofing datasets.
Key Features:
ViT architecture with DINO self-supervised pre-training for robust feature extraction
Trained on CelebA-Spoof and CASIA-SURF benchmark datasets
Detects spoofing attacks including print attacks, replay attacks, and 3D mask attacks
Built with PyTorch
Tech Stack: Python · PyTorch · Vision Transformer (ViT) · DINO · Computer Vision
